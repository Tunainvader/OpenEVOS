# Bundled fonts

| File | Family | Licence |
|---|---|---|
| Inter-Regular/Medium/SemiBold/Bold.otf | Inter (Rasmus Andersson) | SIL Open Font License 1.1 |
| JetBrainsMono-Regular/Medium.ttf | JetBrains Mono (latin subset, converted from the @fontsource woff) | SIL Open Font License 1.1 (OFL-JetBrainsMono.txt) |

Both licences allow bundling with software. If a font fails to load, the UI falls back to the system
sans-serif / monospace font.
